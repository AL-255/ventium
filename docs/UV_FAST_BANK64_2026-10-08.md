above eight data pages. The replacement retains **16 sets × 4 ways** and maps
both tags and payload to distributed FPGA RAM. Relative to the first banked
layout, routed leaf cost falls **782 → 370 LUTs**, **1,696 → 96 registers**;
physical-query delay falls **2.758 → 2.079 ns**. No pipeline stage, ISA rule,
permission bypass or Quake-specific behavior was added.

Fresh independent leaf, actual-parent and both synthesized/routed vendor-model
scoreboards pass. Fresh matched full-core builds pass the capacity matrix,
permission/stack checks, 48 retirement-state cases and 32 shift/branch cases.
The capacity matrix observes actual same-clock U/V pairs; both candidates use
the system fast path. Its warm timings match the no-translation-cut control
through 64 pages. These are bounded microtests, not gameplay measurements.
See the [source, limitations and exact results](../verif/fe_pipe/banked/README.md).
